# Chess II

A 10 × 10 chess variant with Archers, Wizards, Catapults, Jokers and a wild Dragon, against a built-in engine.
It runs entirely in the browser, and works offline once it has been opened.

## Put it on GitHub Pages

1. Create a new public repository on github.com (for example `chess-ii`).
2. Choose **uploading an existing file**, drag in everything from this folder, and commit.
3. Open **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. After a minute the game is live at `https://<your-username>.github.io/chess-ii/`.

## Add it to an iPhone home screen

1. Open that address in **Safari**.
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Open it once from the home screen while online. After that it works with no connection.

## Updating

Upload the new files over the old ones. The next time the app is opened online it fetches the new version,
and the version after that opens with it.
